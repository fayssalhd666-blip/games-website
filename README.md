# Games Website

بوابة الألعاب الإلكترونية هو مشروع موقع عربي يبسط تجربة عشاق الألعاب عبر الإنترنت.  
يوفر الموقع:
- صفحة رئيسية ترحيبية قابلة للتفاعل.
- مراجعات لأشهر الألعاب مثل FIFA و Valorant.
- قسم أخبار الألعاب.
- صفحة خاصة لتحميل تطبيق لعبة FIFA 2023.
- دعم تغيير الوضع بين الضوء والداكن.

## كيفية الاستخدام
- افتح **index.html** في متصفحك وستجد كافة الميزات.
- يمكنك تعديل الملفات بسهولة من خلال VS Code أو أي محرر نصوص تفضله.

## كيف تنشر الموقع
يمكنك نشر الموقع على الإنترنت مجاناً باستخدام [GitHub Pages](https://pages.github.com) عبر رفع الملفات لهذا المستودع، وتفعيل النشر من الإعدادات.

تم برمجة وتصميم الموقع ليكون سهل الاستخدام والتطوير. إذا أردت إضافة ألعاب أخرى أو ميزات إضافية فقط قم بتعديل الملفات!
